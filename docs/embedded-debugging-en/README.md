# QCCOM debugging guides

Three short, reproducible examples for embedded developers. The supplied records and files are teaching fixtures. No board, production broker, or downloadable executable is included.

- [Replay a UART capture and compare raw data with its plot](01-serial-replay.md). Includes a 16-line timed log.
- [Find a stale retained MQTT message](02-mqtt-local-debug.md). Uses a Mosquitto broker bound to loopback.
- [Find a UART framing change in two firmware source trees](03-firmware-diff.md). Includes a pair of sample trees.
